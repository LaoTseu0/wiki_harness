## Vue d'ensemble

Un recruteur croit un repo qui tourne, pas une certification — et
certaines offres (Mirakl) demandent le lien GitHub dans le CV
([roadmap §10.3](../../roadmap.md)). La section couvre le GitHub public
en anglais (chaque README au même canon) et la stratégie d'extraction
des modules en repos dédiés.

## Synthèse

Le portfolio n'est pas un livrable de fin : c'est la **projection
publique** de chaque module au fil de l'eau. Chaque tableau d'evals,
chaque post, chaque threat model produit ailleurs dans le parcours
trouve ici sa vitrine. **Auto-contrôle** : chaque repo public
répond-il aux quatre questions du canon (problème, architecture,
métriques, ce que je referais) ?
