# Glossaire

Définitions courtes des termes techniques qui **n'ont pas de leçon à eux**.

Règle de liaison, quand une leçon emploie un terme :

1. si le terme a **sa propre leçon**, le lien pointe vers elle ;
2. sinon, vers **sa définition ici** — créée si elle manque.

Une entrée de glossaire n'est pas une leçon : ni étape, ni mesure, ni
promotion. Juste de quoi ne pas rester bloqué sur un mot. Le jour où un
terme mérite d'être refait à la main, il quitte le glossaire pour devenir
une leçon.
