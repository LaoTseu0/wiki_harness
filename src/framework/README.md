# framework

Vide, et c'est normal : ce dossier se remplit **par promotion**.

Quand une leçon est comprise — pas lue, comprise : le code écrit à la main
tourne et on sait dire pourquoi chaque ligne est là — la brique réutilisable
qui en sort est déplacée ici depuis `etapes/`, nettoyée (typée, testée), et
la leçon gagne une section « Ce que ça change dans le framework ».

Sous-paquets attendus au fil du parcours : `llm/` (providers), `outils/`,
`agent/` (la boucle), `memoire/`, `retrieval/`, `evals/`. Aucun n'est créé
d'avance — un dossier vide n'est pas une architecture, c'est une intention.
