# Générateur du parcours

Ce dossier rassemble les entrées et les outils employés pour produire et
contrôler le contenu du Wiki.

## Organisation

- `guardrails/parcours/` contient les règles générales, la cartographie et les
  modèles de leçon ;
- `guardrails/schema/` contient les registres visuels, les Canvas canoniques et
  les vues contextualisées générées ;
- `tools/` contient les scripts de génération et de vérification.

Le fichier `AGENTS.md` conservé à la racine sert uniquement de point d'entrée
pour les agents qui découvrent leurs instructions depuis la racine du dépôt.
