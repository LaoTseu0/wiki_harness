# Section - Mesures

## Contrat de génération

- **Input** — reconstruction validée et résultats bruts disponibles.
- **Dépendance de section** — `reconstruction`.
- **Output** — fragment `## Mesures`.

## Mesures

Une mesure indique :

- l'hypothèse ;
- le matériel et les versions ;
- l'entrée et la charge ;
- la métrique ;
- plusieurs répétitions lorsque la variance compte ;
- le résultat brut ;
- l'interprétation autorisée.

Une valeur issue d'une documentation n'est pas présentée comme une mesure du
projet.
