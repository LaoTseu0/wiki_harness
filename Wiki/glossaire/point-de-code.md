# point de code

Nombre attribué par Unicode à un caractère abstrait. Un symbole visible peut
réunir plusieurs points de code.

Le « é » précomposé correspond à U+00E9. La suite U+0065 U+0301 peut s’afficher de la
même manière, tout en comptant deux points de code.
